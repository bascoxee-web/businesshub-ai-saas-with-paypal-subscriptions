# BusinessHub VisionAI

Private-pilot business management app: clients, projects/tasks, invoices, evidence-based SEO reports, a Gemini assistant with confirmed actions, password recovery, and PayPal sandbox subscription testing.

**Not deployed.** Database proposals have not been applied to VisionGrader. Live subscription billing and paid entitlements are not implemented or enabled. Read `INTEGRATION.md` and `CLOUDFLARE.md` before setup.

## Run locally

Use Node 22 or newer. Run `npm ci`, copy `.env.example` to `.env.local`, and fill values directly in your environment. Never commit keys. Run `npm run dev`.

`GEMINI_MODEL` must name a function-calling model available in your Google AI Studio project. Google AI Pro and API billing are separate. No paid provider calls were made in verification.

## Validate

- `npm run typecheck`
- `npm test`
- `npm run build:cloudflare` — builds the Next.js app and Cloudflare Worker without deploying.

The OpenNext adapter is pinned with a compatible Next.js patch. Runtime requests use HTTP services; no direct Postgres/TCP connection is required.

## Database

The app targets the `businesshub` schema. `database/proposals/businesshub-shared-project.sql` is the review-only shared-project setup, generated by `python3 scripts/build-shared-schema.py`. It creates a separate schema with RLS and explicit workspace onboarding. It does not install a global Auth sign-up trigger or migrate Grader records.

**Do not run the historical files in `supabase/migrations` against VisionGrader.** They are fresh-project regression fixtures. The proposals are not Supabase migration history; CLI migration/advisor validation and live-project review are still required before application.

## Payments

Invoice payments use the existing Orders/Webhooks integration. Subscription checkout is a separate sandbox-only workflow under `/app/billing`: reserve checkout, approve in PayPal, verify status server-side, cancel if needed. Configure sandbox plan IDs after creating approved test plans. Prices are shown by PayPal before approval; no public prices are invented here.

Subscription approval does not change the workspace plan. Automatic paid entitlement updates, subscription webhook lifecycle handling, renewal failure/refund handling and production activation remain launch work.

## SEO

Live audits call Firecrawl with server-only credentials, fresh single-page retrieval, bounded results and plan-based attempt allowances. Failed attempts consume allowance to bound provider spending. HTML snapshots can be checked separately. Detected signals are not Google rankings, traffic or a multi-page audit.
